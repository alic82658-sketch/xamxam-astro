Supprimer une conversation ne supprime plus forcément le contrat, la facture ou le tableau Excel qu'on lui avait joint. ChatGPT conserve désormais automatiquement ces fichiers dans une bibliothèque séparée, jusqu'à ce que l'utilisateur les efface lui-même.

La nouveauté peut être utile. Un utilisateur n'a plus besoin de rechercher une ancienne conversation pour retrouver un document envoyé à ChatGPT. Il peut ouvrir Library, parcourir ses fichiers, les télécharger ou les réutiliser dans une nouvelle demande.

Mais cette facilité modifie une règle de prudence importante. OpenAI précise que les conversations et les fichiers de Library doivent être gérés séparément : **effacer le chat contenant un document n'efface pas le document enregistré dans Library**.

## Quel problème concret pour une petite entreprise ?

Prenons le cas d'un gestionnaire immobilier à Dakar. Il envoie dans ChatGPT un projet de bail, l'état des lieux d'un appartement, une facture de réparation ou un document contenant les coordonnées d'un locataire.

Après avoir obtenu son résumé, il supprime la conversation en pensant avoir retiré l'ensemble des documents. Ce n'est plus suffisant.

Le PDF ou le tableur peut rester dans Library, accessible depuis son compte, jusqu'à sa suppression manuelle. Cela ne signifie pas que le fichier devient public ou qu'une fuite s'est produite. Cela signifie simplement que sa durée de conservation ne dépend plus automatiquement de celle du chat.

Pour une entreprise, la différence est importante : un document qu'on croit supprimé peut encore être retrouvé par toute personne ayant accès au compte ChatGPT concerné.

## Que peut faire ChatGPT Library ?

Selon la [documentation officielle d'OpenAI](https://help.openai.com/en/articles/20001052-file-storage-and-library-in-chatgpt), Library regroupe les fichiers envoyés ou générés dans ChatGPT, notamment les documents, PDF, feuilles de calcul, présentations et images.

L'utilisateur peut filtrer la recherche selon le type de fichier, télécharger plusieurs éléments ou rattacher un ancien fichier à une nouvelle conversation. Le stockage est séparé des limites quotidiennes de pièces jointes.

Les capacités annoncées sont les suivantes :

- 500 Mo pour ChatGPT Free ;
- 4 Go pour ChatGPT Go ;
- 20 Go pour ChatGPT Plus et Business ;
- 100 Go pour ChatGPT Pro.

Library est disponible sur le Web. OpenAI ne confirme pas encore sa disponibilité complète sur Android et iPhone. La documentation mentionne les forfaits concernés, mais ne cite pas explicitement le Sénégal : l'apparition effective de Library doit donc être vérifiée dans la barre latérale de chaque compte.

Google Drive peut également apparaître dans Library lorsqu'il est connecté. Les fichiers concernés restent toutefois dans Drive : ils ne peuvent pas être supprimés depuis ChatGPT. Il faut intervenir directement dans Google Drive.

## Comment supprimer réellement un document ?

La procédure décrite par OpenAI est la suivante :

1. Ouvrir **Library** dans la barre latérale de ChatGPT sur le Web.
2. Rechercher le fichier concerné.
3. Cliquer sur **Delete** ou sur l'icône de corbeille.
4. Vérifier l'espace **Recently deleted**, lorsqu'il est présent.
5. Choisir **Delete forever** pour demander une suppression définitive plus rapide.

Après cette opération, le document disparaît immédiatement de la bibliothèque principale. Sa suppression permanente des systèmes d'OpenAI est normalement programmée dans un délai maximal de 30 jours, sauf obligation de conservation liée à la sécurité ou à la loi.

La [politique de conservation de ChatGPT](https://help.openai.com/en/articles/8983778-chat-and-file-retention-policies-in-chatgpt) confirme donc deux opérations distinctes : supprimer la conversation, puis supprimer le fichier dans Library.

## Les fichiers peuvent-ils servir à entraîner les modèles ?

Pour les comptes individuels, OpenAI peut utiliser les contenus envoyés, y compris les fichiers, lorsque l'option **Improve the model for everyone** est activée.

On peut la désactiver dans **Paramètres → Data Controls → Improve the model for everyone**. La désactivation s'applique ensuite au compte sur le Web et sur mobile. Les conversations restent visibles dans l'historique, mais ne sont plus utilisées pour améliorer les modèles.

Les contenus des espaces Business, Enterprise et Edu ne servent pas par défaut à l'entraînement des modèles. OpenAI détaille ces réglages dans sa [FAQ sur les contrôles des données](https://help.openai.com/en/articles/7730893-data-controls-faq).

Désactiver l'entraînement ne supprime toutefois pas les fichiers déjà présents dans Library. Il faut toujours les effacer séparément.

## Le chat temporaire devient-il préférable ?

Pour une analyse ponctuelle, le chat temporaire offre une protection supplémentaire : OpenAI confirme que les fichiers qui y sont envoyés ne sont pas enregistrés dans Library.

La conversation temporaire peut néanmoins être conservée dans les systèmes pendant un maximum de 30 jours pour la surveillance des abus. Elle n'apparaît pas dans l'historique et n'est pas utilisée pour entraîner les modèles.

Cette fonction ne justifie pas l'envoi de n'importe quel document. Un entrepreneur ne devrait toujours pas transmettre inutilement :

- un mot de passe ou un code reçu par SMS ;
- des coordonnées bancaires complètes ;
- la copie intégrale d'une pièce d'identité ;
- un fichier contenant toute sa clientèle ;
- un dossier médical ;
- un contrat confidentiel non anonymisé.

Lorsque seule une clause doit être expliquée, il vaut mieux isoler le passage nécessaire et masquer les noms, numéros, signatures et coordonnées.

## La méthode prudente pour une PME

Une entreprise peut adopter quatre règles simples :

1. utiliser un compte professionnel distinct du compte personnel ;
2. désactiver l'utilisation des contenus pour l'entraînement lorsque des documents professionnels sont traités ;
3. préférer le chat temporaire pour une analyse ponctuelle ;
4. contrôler régulièrement Library et supprimer les fichiers devenus inutiles.

L'intelligence artificielle peut classer, résumer ou comparer les documents. La décision de les conserver, de les anonymiser ou de les supprimer reste humaine.

## Ce qui est confirmé et ce qui reste à vérifier

**Confirmé :** les fichiers envoyés et créés sont automatiquement enregistrés dans Library ; supprimer le chat ne supprime pas le fichier ; le forfait gratuit comprend 500 Mo ; les fichiers d'un chat temporaire ne sont pas enregistrés dans Library ; les fichiers supprimés sont normalement effacés définitivement sous 30 jours.

**À vérifier :** l'apparition effective de Library sur tous les comptes sénégalais, la date de disponibilité complète sur Android et iPhone, la traduction intégrale de l'interface en français et les conséquences exactes lorsqu'un compte dépasse sa limite de stockage.
